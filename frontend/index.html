About the Project

        NMIMS IVP+AI
      

      

        IVP+AI: AI-Based Document Understanding and Information Extraction System is a modular, production-ready document processing platform designed to ingest raw scanned documents, apply conservative image enhancement, run optical character recognition (OCR) with Tesseract, and infer semantic meaning using forward-chaining rule engines.
      

      

        

          
Image Processing Pipeline

          
    
            
  • File integrity validation and MIME check
    • 
            
  • EXIF transpose and orientation correction
    • 
            
  • Single-channel grayscale conversion
    • 
            
  • Bicubic upscaling for low-resolution text (< 1000px)
    • 
            
  • Histogram autocontrast and 1.15x boundary enhancement
    • 
            
  • Direct Tesseract adapter with PSM 3 segmentation

  • Structured invoice field recognition
    • 
            
  • In-memory knowledge base isolating inferred facts
    • 
            
  • Forward-chaining inference engine (fixed-point loop)
    • 
            
  • Decoupled REST API communication over HTTP
