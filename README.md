

\# IVP+AI

\## AI-Based Document Understanding and Information Extraction System



\### Overview

A modular system for processing documents, extracting relevant

information, and converting unstructured content into structured data.



\### Architecture

\- Layer 1: Primary implementation.

\- Layer 2: Temporary demonstration module.

\- Layer 3: Temporary demonstration module.

\- REST API: Interface for communication and integration.

\- Shared schemas: Common data contracts between modules.



\### Modules

\- `backend/` — REST API and integration logic.

\- `modules/image-processing/` — Image processing.

\- `modules/ai-engine/` — AI-based information extraction.

\- `modules/demo-layers/` — Temporary demonstration components.

\- `shared/` — Shared schemas and JSON examples.

\- `docs/` — Requirements and architecture documentation.

\- `samples/` — Sample data references and test resources.



\### Collaboration

Contributors should work on separate Git branches and integrate

changes through pull requests.
